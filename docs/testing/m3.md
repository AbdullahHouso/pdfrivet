# M3 test checklist: page tools (0.3)

Test on Windows with `bun tauri dev` (pull, then `bun install` if `package.json` changed).
Use a few PDFs: a small one, the 1,440-page one, an Arabic one, one with form fields and one
with bookmarks. Check light and dark themes, and English and Arabic (Settings → Language).

## Organize pages
- [ ] Tools (grid icon, top right) → Organize pages: every page shows as a thumbnail; the size
      slider makes them bigger or smaller; scrolling through 1,440 pages stays smooth.
- [ ] Click selects one page; Ctrl+click adds or removes; Shift+click selects a range; Ctrl+A all.
- [ ] Drag one page, then several, to a new place: an orange line shows where they go, a badge
      shows how many; near the top or bottom edge the view scrolls.
- [ ] Rotate left/right, Duplicate, Delete (button and the Delete key), Insert blank page,
      Insert pages from a file (choose a PDF; its pages are marked with +).
- [ ] Ctrl+Z / Ctrl+Y undo and redo inside Organize pages; deleting every page is refused.
- [ ] Cancel with changes asks first; Escape clears the selection, then cancels.
- [ ] Done: the document shows the new order; the tab is marked unsaved; Ctrl+Z puts every page
      back in one step, Ctrl+Y redoes it. Save, reopen: the order and rotations are kept.
- [ ] Bookmarks point to the right pages after moving pages; bookmarks of deleted pages are gone.
- [ ] Form fields on moved pages still work after saving.
- [ ] Arabic: the grid starts on the right, dragging and the insertion line follow it.
- [ ] A file whose author forbids changing pages: Organize and the page items are disabled with
      a reason.

## Thumbnail menu and Extract
- [ ] Right-click a thumbnail: Rotate clockwise/counter-clockwise, Delete page, Extract page…,
      Organize pages. Each rotate or delete is one Ctrl+Z.
- [ ] Tools → Extract pages…: type "1-3, 5" (also with Arabic digits ١-٣); the save dialog suggests
      "name (pages 1-3, 5).pdf"; the new file has those pages. "Delete them from this document"
      removes them here (one Ctrl+Z brings them back). The message at the bottom opens the file
      or shows it in its folder.

## Merge
- [ ] Start page → Merge PDFs, and Tools → Merge PDFs… with a document open (it's listed first).
- [ ] Add files…: several at once; reorder with the arrows; remove one; type pages for one
      ("2-4"); a password-protected file asks for its password in its row (wrong password says so).
- [ ] Merge…: the save dialog suggests "Merged.pdf" next to the first file; the progress bar moves;
      the merged file opens in a new tab with every page in order.
- [ ] Bookmarks: one per file (named after it), each file's own bookmarks under it, pointing at the
      right pages. Untick "Add a bookmark for each file": the files' own bookmarks follow each other.
- [ ] Merge the same form PDF twice: the fields of both copies can be filled separately, and keep
      their values after saving and reopening (also in Edge or Acrobat).
- [ ] Arabic file names and documents merge fine; the list reads right to left in Arabic.

## Split
- [ ] Tools → Split…: every 1, 2 and 10 pages; "Makes N files" updates as you type.
- [ ] By page ranges "1-3, 4-10, 11" (and with Arabic digits): three files, those pages each.
- [ ] At each bookmark (a file with chapters): one file per top-level bookmark, named
      "name - Chapter title.pdf" (Arabic titles too; characters Windows forbids are left out).
- [ ] Choose… another folder; split twice into the same folder: the second time the files get
      " (2)" instead of overwriting.
- [ ] The message at the bottom: Show in folder opens Explorer with the first file selected.
- [ ] The parts keep the title and author (Document properties) and their bookmarks.
- [ ] Split the 1,440-page file every page: the progress bar moves and the app stays responsive.

## Password protection
- [ ] Tools → Password protection…: set a password to open (typed twice; a short one gets a hint);
      Protect and save. Reopen the file: it asks for the password; a wrong one is refused. Edge
      and Acrobat ask for it too.
- [ ] Restrictions only (no password to open), allowing printing only: the file opens without a
      password; copying text, comments and Organize are disabled; Print works. Untick printing
      too: Print is disabled with a reason (also in Edge/Acrobat).
- [ ] Open the restricted file and open the dialog: it asks for the permissions password; a wrong
      one is refused; the right one shows the options and "Remove protection".
- [ ] Remove protection, save: the file opens without a password anywhere.
- [ ] An existing protected file from elsewhere (AES-256, e.g. made by Acrobat): its restrictions
      are respected now (copying blocked if the author blocked it).
- [ ] Arabic passwords (letters typed in the Arabic layout) work to open the file again.
