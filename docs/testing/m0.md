# M0 test checklist (Windows)

## First time

```powershell
git clone git@github.com:AbdullahHouso/pdfrivet.git C:\dev\rivet-pdf
cd C:\dev\rivet-pdf
cargo xtask fetch-pdfium
cd app
bun install
bun tauri dev
```

## Afterwards

```powershell
cd C:\dev\rivet-pdf
git pull
cd app
bun install
bun tauri dev
```

The first build takes several minutes; later builds are much faster.

## Checks

- [ ] The PDFRivet window opens and shows the start screen.
- [ ] **Open PDF…** opens a file picker filtered to PDF files.
- [ ] Opening `tests\fixtures\basic.pdf` shows "Rivet fixture: basic", page 1 of 3.
- [ ] The next/previous buttons and PageDown/PageUp change pages; page 3 is landscape.
- [ ] Zoom buttons and Ctrl + / Ctrl − change the zoom; text stays sharp.
- [ ] Open `tests\fixtures\arabic.pdf`: Arabic text is shaped correctly.
- [ ] Open one of your own PDFs (e.g. a large or Arabic one).
- [ ] Opening `tests\fixtures\broken.pdf` shows a translated error, not a crash.
- [ ] Switch the language to العربية: the toolbar mirrors (RTL) and all text is Arabic.
- [ ] Restart the app: the chosen language is remembered.
- [ ] With Windows display language set to Arabic and no saved choice, PDFRivet starts in Arabic.
