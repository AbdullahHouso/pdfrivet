# Text, search, annotations and signatures — test checklist (Windows)

## Get the latest code

```powershell
cd C:\dev\rivet-pdf
git pull
cargo xtask fetch-pdfium
cd app
bun install
bun tauri dev
```

## Selecting and copying text

Use `tests\fixtures\basic.pdf`, `tests\fixtures\arabic.pdf` and some real PDFs (Arabic and English).

- [ ] In Select mode (V) the pointer becomes a text cursor over text.
- [ ] Dragging selects text; the selection follows the lines, also across two pages.
- [ ] Dragging past the bottom of the window scrolls and keeps selecting.
- [ ] Double-click selects a word, triple-click a line; Shift+click extends the selection.
- [ ] Ctrl+A selects the whole document; Escape or a click elsewhere clears the selection.
- [ ] Ctrl+C copies; paste into Notepad and Word: same text, same order, line breaks kept.
- [ ] Arabic: drag from right to left selects the words you passed over; pasted Arabic reads correctly
      (letters joined, words in the right order). Mixed lines (Arabic + English + numbers) too.
- [ ] Right-click on a selection shows Copy and Select all; the menu closes on Escape or a click elsewhere.
- [ ] Links and form fields still work with a single click in Select mode.
- [ ] Rotate the view and select again: the highlight sits on the text.
- [ ] In Hand mode (H) dragging pans and doesn't select.

## Search

- [ ] Ctrl+F opens the find bar; typing highlights results on the pages and shows "1 of N".
- [ ] Enter / Shift+Enter and F3 / Shift+F3 move to the next / previous result, scrolling to it, and wrap around.
- [ ] With text selected, Ctrl+F (or right-click → Search for selected text) searches for it.
- [ ] Search starts from the page you're on: the first result shown is the first one on or after it.
- [ ] `arabic.pdf`: "مرحبا", "مَرحبا", "وارقام", "للاختبار" and "123" are each found once.
- [ ] A real Arabic PDF with diacritics (e.g. a Quran or poetry PDF): typing without diacritics finds the words.
- [ ] Match case ("Aa") and whole words ("ab") change the results right away.
- [ ] The list button (or the sidebar's Search tab) lists every result with its page and surrounding text; clicking one shows it.
- [ ] A long PDF (`make-test-pdf big.pdf --pages 2000`, search "of 2000"): results appear while searching, scrolling stays smooth.
- [ ] Escape or × closes the bar and removes the highlights.

## Annotations

Use a copy of a PDF. Open the Annotate toolbar with the pen button or A.

- [ ] Highlight / Underline / Strikeout: select text with the tool active; the mark appears when you release.
      Also from the right-click menu on a selection. Works across two pages and on Arabic text.
- [ ] Pen: draw a few strokes, quickly and slowly; lines are smooth and where you drew them.
- [ ] Rectangle, Ellipse (hold Shift for a square / circle), Line, Arrow (Shift: 45° steps).
- [ ] Sticky note: click to place it; type a comment; click elsewhere; click the note again: the comment is there.
- [ ] Colour swatches, Other colour…, width and opacity change what you draw next; "Fill" fills rectangles/ellipses.
      Restart PDFRivet: the tool styles are remembered.
- [ ] Click a drawing/shape/note (Select tool): a dashed frame with handles and a small menu appear.
      Drag to move, drag a handle to resize, change its colour, add a comment, delete it.
- [ ] Click a highlight: it's selected; change its colour; press Delete.
- [ ] Eraser: drag across drawings and shapes; they disappear (highlights and notes stay).
- [ ] Ctrl+Z / Ctrl+Y (and the toolbar arrows) undo and redo each of the above, including deletes and moves.
- [ ] The tab shows unsaved changes; Ctrl+S saves. Reopen the file: everything is still there.
- [ ] Open the saved file in Edge, Chrome and Adobe Acrobat (if you have it): the same marks, drawings and notes appear,
      notes show their comments, and the author is your name (Settings → General → Your name).
- [ ] Rotate the view and draw/move things: they land where the pointer is.
- [ ] Hand mode (H) still pans the page while the Annotate toolbar is open.
- [ ] Memory: annotate 20+ pages of a long PDF and scroll around; memory stays reasonable (compare with before).

## Annotations from other apps, undo, scans

Use a PDF annotated on an iPad/iPhone (Apple highlighter) or in Xodo/Acrobat, e.g. your
"حل الأقسام الجديدة" file (a copy).

- [ ] Drag a highlighter stroke: while dragging only the moved copy shows; after dropping it keeps
      its rounded ends and transparency. Resize it: same look, stretched.
- [ ] Erase a few strokes in one eraser drag, then Ctrl+Z once: all come back exactly as they were.
- [ ] Delete an annotation, save, then Ctrl+Z: it comes back. Save again and reopen: it's there.
- [ ] On a scanned page (no selectable text) drag with Highlight / Underline / Strikeout: the area is marked.
- [ ] Open the saved file in Acrobat/Edge: area highlights show as highlights.

## Redaction

- [ ] Annotate → Redact. Drag over an area of a scanned page and select a few words on a text page:
      both show a red outline with ×; × removes a mark; "Apply N redactions" shows the count.
- [ ] Save: a confirmation explains it can't be undone; "Redact and save" blacks the areas out.
- [ ] The rest of each redacted page looks exactly as before (colours, header strips, handwriting).
- [ ] Text outside the black boxes can still be selected and found with Ctrl+F; text under them can't.
- [ ] Reopen the saved file in PDFRivet, Edge and Acrobat: black boxes, nothing under them
      (try selecting/copying over a box in Acrobat).
- [ ] A password-protected PDF says redaction isn't possible yet.

## Text boxes and fonts

- [ ] Type Arabic in the find box, the page box, a note's comment and Settings → Your name: it's
      drawn in the same font as the rest of the app (Rubik), letters joined.

## Signatures

- [ ] Annotate → Signature: with no saved signature, the "New signature" dialog opens.
- [ ] Draw: sign with the mouse, then with a pen or touch screen if you have one; strokes are smooth.
      Change the ink colour; Clear; Use signature.
- [ ] The signature follows the pointer; a click puts it down, selected; move and resize it.
- [ ] From a picture: photograph your signature on white paper with your phone, copy the photo to the PC,
      choose it. The paper disappears (checkerboard behind); the slider adjusts it. Use it; place it on a page
      with a coloured background or text: only the ink shows.
- [ ] "Save this signature for next time": the Signature button now lists it; it can be deleted (trash).
      Restart PDFRivet: still listed.
- [ ] Undo/redo placing, moving and deleting a signature.
- [ ] Save, reopen in PDFRivet and in Edge/Acrobat: signatures look the same, picture signatures keep their transparency.

## Animations

- [ ] Menus (☰, page display, Open recent, saved signatures, right-click) fade and drop in, and fade out.
- [ ] Dialogs (Settings, About, Print, Properties, a password, Save changes?) rise in with the dimmed
      background and fade out, whether closed with ×, Cancel or Escape.
- [ ] Tooltips fade in and out; moving along the toolbar swaps them without delay.
- [ ] Find bar, Annotate row, sidebar, a new tab, the annotation menu and comment box appear smoothly.

## Tabs and page turns

- [ ] The + button (or Ctrl+T) opens a "New tab" with the start page; choosing a file opens it;

- [ ] Continuous: scrolling back to pages you just saw shows them at once.
- [ ] Annotate → Redact → "Apply N redactions" asks first.

## Bookmarks

- [ ] Ctrl+B on a page: a bookmark appears in the Bookmarks tab, ready to rename. With text
      selected, the text is its title.
- [ ] Right-click a thumbnail or a page → Add bookmark.
- [ ] Rename (double-click / F2), delete (Delete), drag to reorder, drop on another to nest it,
      Alt+↑/↓/←/→ move. Ctrl+Z undoes each change.
- [ ] Save, reopen: same bookmarks. Open the file in Edge or Acrobat: the bookmarks are there,
      Arabic titles included, and clicking one goes to its page.
- [ ] A PDF that already has bookmarks: edit them, save, and its links still work.

## Comments

      its edge resizes it.
- [ ] Every annotation is listed by page; highlights quote their text, drawings show a small picture.
- [ ] Click a card: the page scrolls to the annotation and selects it. Select one on the page:

- [ ] Save, open in Acrobat: the reply shows under its comment (not as a separate note icon).

## Text boxes

- [ ] Annotate → Text (or T), click and type English, Enter, then Arabic: the box grows, letters
      join, each line runs its own way. Escape (or a click outside) finishes; the page shows the
      same text in the same place.
- [ ] A box that starts with Arabic grows to the left from where you clicked.
- [ ] Mixed "مرحبا PDFRivet 2026": the English part sits to the left of the Arabic word.
- [ ] Font picker: Rubik, Amiri and your Windows fonts (Arial, Segoe UI, Traditional Arabic,
      Sakkal Majalla…); each name shows in its font. A Latin-only font still shows Arabic (a bundled
      font fills in).
- [ ] Size (and Ctrl+[ / Ctrl+] while typing), bold, colour, across (start/left/centre/right),
      down (top/middle/bottom, after making the box taller), direction (auto/RTL/LTR).
- [ ] Drag a box's side: lines wrap; drag its bottom: room for the text; double-click a handle:
      back to fitting the text. Move it. Double-click (or Enter) edits it. Ctrl+Z undoes.
- [ ] Save, reopen: same boxes. Open in **Acrobat**: they look the same and can be clicked and
      edited there. Open in Edge and PDFgear: they look the same.
- [ ] A PDF with a text box from PDFgear whose Arabic is broken: edit it in PDFRivet, it's fixed.

```powershell

bun tauri build --bundles nsis
.\..\target\release\bundle\nsis\PDFRivet_*_x64-setup.exe
```

      Extra large icons, in light and dark mode. If an old icon sticks, sign out and in (icon cache).
- [ ] The desktop and the Start menu still show the app icon (dark tile) for PDFRivet itself.
- [ ] Uninstall PDFRivet: PDFs go back to the previous app's icon.
