# M1 test checklist (Windows) — PDFRivet 0.1 "Reader"

## Get the latest code

```powershell
cd C:\dev\rivet-pdf
git pull
cargo xtask fetch-pdfium
cd app
bun install
bun tauri dev
```

## Opening files

- [ ] **Open PDF…** (or Ctrl+O) lets you pick several PDFs; each opens in its own tab.
- [ ] Dragging PDFs from Explorer onto the window opens them (an outline appears while dragging).
- [ ] Opening a file that is already open just switches to its tab.
- [ ] `tests\fixtures\password.pdf`: a password dialog appears. `wrong` shows an error, `rivet` opens it.
- [ ] `tests\fixtures\broken.pdf` shows a translated error, not a crash.

## Reading

- [ ] Pages scroll continuously; mouse wheel, PageUp/PageDown, arrows, Space, Home/End all work.
- [ ] Type a page number in the toolbar box and press Enter; Ctrl+G jumps to the box.
- [ ] Zoom: +/− buttons, Ctrl+wheel (zooms around the mouse), touchpad pinch, Ctrl+0 (fit width).
- [ ] Zoom menu: Fit width, Fit page, percentages. Text is sharp after zooming.
- [ ] `tests\fixtures\links.pdf`: "Go to page two" jumps to page 2; "Visit example.com" opens your browser.
      Links highlight when you hover them, also after rotating or zooming.
- [ ] Rotate view turns pages clockwise; four clicks return to normal at the same place.
- [ ] Generate a big file and scroll quickly through it:
      `cargo run --release -p rivet-cli -- make-test-pdf big.pdf --pages 2000`

## Forms and saving

Use a copy of `tests\fixtures\forms.pdf` (and any real forms you have, e.g. government or bank forms):

- [ ] Clicking the checkbox ticks/unticks it; Red/Blue behave as a group.
- [ ] Clicking "Name" opens a text box; type English and Arabic, press Enter → the text appears in the field.
- [ ] Escape while typing cancels; the drop-down "Country" lets you choose another country.
- [ ] "Locked" can't be changed.
- [ ] After a change, the tab shows a ● and the Save button turns on.
- [ ] Ctrl+S saves over the file (works while the file is open); the ● disappears.
- [ ] Menu → Save as… (Ctrl+Shift+S) saves a copy under a new name; the tab now shows that file.
- [ ] Reopen the saved file in PDFRivet **and** in Edge/Chrome/PDFgear: all values are there.
- [ ] Closing a tab with changes asks Save / Don't save / Cancel; each does what it says.
- [ ] Closing the window with unsaved changes asks too ("N documents have changes…").

## Toolbar layout

- [ ] Start side (left in English, right in Arabic): sidebar, Open, Save, Print. End side: ☰ menu.
- [ ] Centre: pages ↑ box ↓ · Select/Hand · zoom − % + fit page/fit width/actual size · page display/rotate. It stays centred when resizing the window.
- [ ] On narrower windows the Open button shows only its folder icon (tooltip still says "Open PDF…").
- [ ] **Hand** (or press H): left-drag moves the page; a simple click still follows links and toggles checkboxes. **Select** (V) brings back normal clicking.

## Page display

- [ ] Toolbar → Page display: **Single page** / **Two pages**.
- [ ] Two pages follow the **document's** language, not the interface: an Arabic PDF puts page 1 on the right even in the English UI, and an English PDF puts page 1 on the left in the Arabic UI.
- [ ] Page display → **Pages right to left** flips that for the current file; reopening the file remembers your choice.
- [ ] **Continuous scrolling** off: one page (or spread) at a time; the wheel, PageUp/PageDown, Space and ←/→ turn pages; the next/previous buttons move by a whole spread.
- [ ] With continuous scrolling off, a page (or spread) shorter than the window sits in the middle.
- [ ] Hold the **middle mouse button** and drag to move around a zoomed-in page (hand cursor while dragging).
- [ ] The three buttons **Fit page**, **Fit width**, **Actual size** work (and show which one is active), also in two-page view.
- [ ] Your choice of page display is used for the next PDF you open.

## Printing (PDFRivet's print dialog)

- [ ] Ctrl+P or the printer button opens PDFRivet's print dialog with your printers (default selected) and a **live preview**.
- [ ] **Printer properties…** opens the HP driver's own window; changes there (e.g. copies, two-sided, paper) appear in PDFRivet's dialog.
- [ ] Pages: All / Current / range like `1-5, 8`; Subset odd/even; Reverse order. The preview's "1 / N" follows your choice.
- [ ] Page sizing: Fit / Shrink oversized / Actual size / Custom %, the preview updates and shows the scale.
- [ ] Paper size list comes from your printer; Orientation Automatic turns landscape pages sideways in the preview.
- [ ] Two-sided (if the printer supports it), Grayscale, Copies + Collate.
- [ ] **Print** really prints, sharp text, matching the preview (try `tests\fixtures\basic.pdf`: A4, Letter, landscape).
- [ ] A 1,000+ page file: printing the current page is quick.
- [ ] "Use the system print dialog…" still works as a fallback.
- [ ] Your printer and sizing choices are remembered for next time.

## Document properties

- [ ] Menu → Document properties… (or Ctrl+D) shows title, author, subject, keywords, creator, producer, dates,
      file name, location (click: opens the folder), size, pages, page size (cm/mm/in/pt), PDF version, tagged, protection.
- [ ] Change the title → OK: the tab name changes and shows ●. Save, close, reopen: the new title is there.
- [ ] Open the saved file in Acrobat or PDFgear → their Document properties show the new title/author too.
- [ ] `tests\fixtures\password.pdf`: fields are read-only with a note; "What this document allows" lists the permissions.

## Sidebar

- [ ] Pages: thumbnails follow the current page; clicking one jumps to it.
- [ ] Outline: `basic.pdf` shows 3 entries; clicking jumps to the page.
- [ ] The sidebar toggle button hides/shows it.

## Tabs

- [ ] Ctrl+Tab / Ctrl+Shift+Tab switch tabs; each tab keeps its page and zoom.
- [ ] Ctrl+W and middle-click close a tab; closing the last one shows the start screen.

## Start screen and memory of where you were

- [ ] Recent files list the documents you opened, newest first, with "x minutes ago".
- [ ] Reopening a recent file returns to the same page and zoom.
- [ ] Renamed/moved files show "File not found"; × removes an entry.

## Look and language

- [ ] Menu → Theme: System / Light / Dark all work and are remembered after restart.
- [ ] Menu → Language → العربية: everything mirrors (tabs, toolbar, sidebar on the right).
- [ ] Window title shows "<document> – PDFRivet".

## Installer (after the v0.1.0 tag builds)

- [ ] Install `Rivet_0.1.0_x64-setup.exe` (SmartScreen: More info → Run anyway).
- [ ] Right-click a PDF in Explorer → **Open with** shows PDFRivet.
- [ ] With PDFRivet already open, double-clicking another PDF opens it as a new tab (no second window).
- [ ] The PDFRivet icon appears in the Start menu, taskbar and title bar.

## Memory (release build)

Use the installed app (not `bun tauri dev`). In Task Manager → Details, add the memory
("Memory (active private working set)") of `pdfrivet.exe` and its `msedgewebview2.exe` processes.
Do the same for PDFgear with the same file.

| Situation | PDFRivet | PDFgear |
|---|---|---|
| Start screen, no file | | |
| `big.pdf` (2000 pages) open, page 1 | | |
| After scrolling to page ~1000 | | |
| 3 tabs open | | |

Budget: **under 150 MB** with a PDF open and scrolled.
